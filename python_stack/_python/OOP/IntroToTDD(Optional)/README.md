## 📝 Description
This assignment focuses on validating algorithm logic using Python's built-in `unittest` framework. By implementing a suite of test cases, I ensured that various functions—ranging from data manipulation to mathematical recursion—handle inputs correctly and return expected outputs, which is a critical practice for maintaining bug-free software.



---

## 🎯 Functions Tested
1. **reverseList:** Reverses a list in-place and checks edge cases like empty or single-element lists.
2. **isPalindrome:** Validates string symmetry against various inputs.
3. **coins:** Calculates the optimal breakdown of coins (Quarters, Dimes, Nickels, Pennies) for a given amount.
4. **factorial:** Validates recursive calculation for factorials.
5. **fibonacci:** Ensures the correct nth Fibonacci number is returned.

---

## 🛠️ Key Concepts
* **Test-Driven Mindset:** Writing code that is verifiable and robust.
* **`unittest` Framework:** Using `assertEqual`, `assertTrue`, and `assertFalse` to validate function outcomes.
* **Recursion:** Testing functions that call themselves (`factorial` and `fibonacci`) to verify base cases and recursive steps.
* **Assertion Testing:** Ensuring that code handles various scenarios (boundary testing) correctly.
