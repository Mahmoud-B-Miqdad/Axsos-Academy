## 📝 Description
This assignment explores the manipulation and iteration of complex data structures in Python. I worked on updating specific values within nested lists and dictionaries and implemented helper functions to iterate through lists of dictionaries, extract specific keys, and print formatted information from dictionary-based structures.

---

## 🎯 Tasks Overview
1. **Update Values:** Modifying specific elements inside nested lists, dictionaries within lists, and lists within dictionaries.
2. **Iterate Through List of Dictionaries:** A function that traverses a list of dictionaries and prints each key-value pair in a human-readable format.
3. **Get Values from List of Dictionaries:** A function that extracts and prints all values associated with a specific key across a list of dictionaries.
4. **Iterate Through Dictionary with List Values:** A function that iterates through a dictionary where values are lists, printing the count and the contents of each list formatted by keys.

---

## 🛠️ Key Concepts
* **Indexing Nested Structures:** Accessing data using multiple keys and indices (e.g., `list[index][key]`).
* **Iteration Logic:** Using nested loops to traverse complex data hierarchies.
* **String Formatting:** Utilizing f-strings and list joins to create clean, readable console output.
* **Dictionary Methods:** Using `.items()` to access both keys and values during iteration.
