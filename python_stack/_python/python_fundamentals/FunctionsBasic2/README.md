## 📝 Description
This assignment bridges the gap between basic loops and advanced list manipulation. Through these challenges, I practiced generating lists dynamically, performing arithmetic based on list indices and length, and implementing conditional filtering on data structures.

---

## 🎯 Tasks Overview
1. **Countdown:** Generates a list that counts down from the given number to 0.
2. **Print and Return:** Prints the first value of a list and returns the second value.
3. **First Plus Length:** Sums the first element of a list with the total length of the list.
4. **Values Greater than Second:** Filters a list to create a new list containing only values greater than the second element of the original list.
5. **This Length, That Value:** Creates a list of a specific size where every element is set to a given value.

---

## 🛠️ Key Concepts
* **Dynamic List Creation:** Using `.append()` to build lists during runtime.
* **Conditional Filtering:** Applying logic to select specific data from an existing set.
* **Boundary Checks:** Handling edge cases (e.g., lists with less than 2 elements in the "Values Greater than Second" task).
* **Looping with Indices:** Using `range()` with parameters for custom iteration steps.
