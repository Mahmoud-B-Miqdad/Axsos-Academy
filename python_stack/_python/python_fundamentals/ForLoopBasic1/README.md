## 📝 Description
This assignment focuses on the fundamental concepts of loops in Python. I implemented several challenges to strengthen my skills in managing ranges, arithmetic operations, and conditional logic (if/else statements).

---

## 🎯 Tasks Overview
1. **Basic:** Print all integers from 0 to 150.
2. **Multiples of Five:** Print all multiples of 5 from 5 to 1,000.
3. **Counting, the Dojo Way:** Print "Coding" for multiples of 5 and "Coding Dojo" for multiples of 10.
4. **Whoa. That Sucker's Huge:** Add odd integers from 0 to 500,000 and print the final sum.
5. **Countdown by Fours:** Print positive numbers starting at 2018, counting down by fours.
6. **Flexible Counter:** A custom counter that prints multiples of a specific number within a given range.

---

## 🛠️ Key Concepts
* **Python Loops:** `for` loops and `range()` function.
* **Conditionals:** `if`, `elif`, `else` statements.
* **Math Logic:** Modulo operator `%` for divisibility checks.
