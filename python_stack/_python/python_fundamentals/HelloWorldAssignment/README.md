## 📝 Description
This assignment introduces the fundamental methods of displaying output in Python. I practiced how to print simple strings, concatenate variables with text, and utilize different string formatting techniques to create clean, readable, and dynamic output messages.

---

## 🎯 Tasks Overview
1. **Basic Print:** Printing static strings.
2. **Concatenation:** Combining strings with other variables using comma separation and the `+` operator.
3. **Type Casting:** Learning how to convert integers to strings using `str()` for concatenation.
4. **String Formatting:** Implementing modern methods to inject variables into strings, including the `.format()` method and f-strings.

---

## 🛠️ Key Concepts
* **Print Function:** The standard output method in Python.
* **Concatenation:** Joining strings together; requires type conversion (e.g., `str(int)`).
* **`.format()` Method:** A versatile way to insert variables into placeholders `{}`.
* **F-Strings (Formatted String Literals):** The most modern and readable way to embed expressions inside string literals using `f"{variable}"`.
