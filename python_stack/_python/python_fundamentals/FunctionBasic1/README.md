## 📝 Description
This assignment is a comprehensive deep dive into how functions work in Python. It focuses on critical concepts such as the difference between `print()` and `return`, the behavior of code after a return statement, variable scoping (local vs global), and the flow of nested function calls.

---

## 🎯 Key Learning Objectives
1. **Return vs Print:** Understanding that `return` terminates a function and sends back a value, whereas `print()` simply outputs to the console.
2. **Function Flow:** Observing how code execution stops immediately once a `return` statement is reached.
3. **Variable Scoping:** Differentiating between local variables inside a function and global variables outside.
4. **Execution Order:** Tracing the sequence of function calls and return values in complex, nested, or sequential scenarios.

---

## 🛠️ Key Concepts
* **Early Exit:** Code following a `return` statement within the same function block is unreachable (dead code).
* **Scope Hierarchy:** Local variables defined inside functions do not overwrite global variables unless explicitly handled.
* **Function Chaining:** Using the result of one function call as an input for another or in an expression.
* **Control Flow:** How `if/else` logic within functions dictates the returned value.
